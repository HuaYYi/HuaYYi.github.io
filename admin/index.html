每个应用是一个独立代码文件，自带名称、样式、参数与渲染逻辑；可以自己写，也可以让 AI 写好后整段贴进「编辑代码」。 内置应用可直接修改，本地改坏了能一键恢复为仓库版本；自定义应用随时可删。单个应用出错只显示错误占位，不会拖垮整站。 本地模式的改动只存在本浏览器，测试满意后到「🚀 提交管理」勾选提交到仓库。

整段 JS 代码：以 SSBApps.define({ id, name, desc, hero, configSchema, css, render }) 开头。 保存时会做语法与注册校验，不通过则不会保存。编辑器内按 Tab 可缩进。

该应用声明的可调参数（来自代码里的 configSchema），保存在 data/pages.json 的 apps 节点，作为所有实例的全局默认；单个板块仍可在「页面管理」里覆盖。

文章、应用代码、页面与配置都先保存在本浏览器中，可以在前台反复测试； 确认可靠后，在这里勾选要提交的文件，一次提交到 GitHub 仓库（随后 Actions 自动构建，约 1~2 分钟上线）。 不勾选的改动继续留在本地，不受影响。
