欢迎使用 Self Static Blog

这是一篇示例文章，用来演示正文排版。访问 /admin/ 登录后台后可以编辑或删除它。

这是一个二级标题

博客使用 原生 HTML / CSS / JavaScript 编写，没有任何前端框架。文章就是一个个独立的 HTML 文件，元数据保存在 posts-list.json 中。

这是一个三级标题

  • 文章通过后台的富文本编辑器撰写，输出的就是原生 HTML
  • 在编辑器里直接 Ctrl + V 粘贴图片，保存文章时会自动上传
  • 编辑器的预览样式与文章页共用同一份 CSS

静态页面没有数据库，每一次保存就是向 GitHub 仓库提交一次 commit。

下面是一个代码块：

// 文章按日期倒序展示
posts.sort(function (a, b) {
  return new Date(b.date) - new Date(a.date);
});

开始使用

  1. 在 GitHub 仓库设置中开启 Pages（Source 选择 GitHub Actions）
  2. 生成一个仅含 Contents 读写权限的 Fine-grained PAT
  3. 访问 /admin/，粘贴 PAT 后即可写文章
