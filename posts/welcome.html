欢迎使用 Self Static Blog

这是一篇示例文章，用来演示正文排版。

这是一个二级标题

博客使用 原生 HTML / CSS / JavaScript 编写，没有任何前端框架。文章就是一个个独立的 HTML 文件，元数据保存在 data/posts-list.json 中。

这是一个三级标题

  • 文章就是原生 HTML，直接在网页里呈现

静态页面没有数据库，每一次保存就是向 GitHub 仓库提交一次 commit。

下面是一个代码块：

// 文章按日期倒序展示
posts.sort(function (a, b) {
  return new Date(b.date) - new Date(a.date);
});
