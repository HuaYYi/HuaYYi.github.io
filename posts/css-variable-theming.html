一套主题色，派生全站配色：CSS 变量工程化实践

这个博客的配置文件里只有一个颜色：theme.primary，比如 #1d6ff2。但页面上实际用到的颜色远不止一个——hover 要变深、标签底色要变浅、边框和阴影各有深浅。这些颜色全都是从那一个主题色「算」出来的。

痛点：手写色值不可维护

最常见的做法是设计稿给什么就写什么：hover 色写死一个 #1660d1，浅底写死一个 #e8f1fe。哪天想换主题色，就得全文件搜索替换，漏掉一处就出现「蓝不太一样的蓝」。

更好的思路是把颜色分成两类：决策（用户选的主色）和推导（由主色按固定规则算出的衍生色）。决策只存一份，推导交给程序。

方案：运行时混色 + CSS 变量注入

因为主色来自用户可改的 JSON 配置，运行时才知道值，所以没法在 SCSS 里预编译，只能在 JS 里现算。核心是一个混色函数：把主色和黑色或白色按比例做线性插值。

// 与黑色混合 → hover 深色；与白色混合 → 浅底高亮
function mix(hex, other, ratio) {
  var c = parseHex(hex), o = parseHex(other);
  var ch = c.map(function (v, i) {
    return Math.round(v * (1 - ratio) + o[i] * ratio);
  });
  return '#' + ch.map(function (v) {
    return ('0' + v.toString(16)).slice(-2);
  }).join('');
}

var dark  = mix(primary, '#000000', 0.28); // 深 28%
var light = mix(primary, '#ffffff', 0.92); // 浅 92%

算完注入 :root：

root.style.setProperty('--primary', primary);
root.style.setProperty('--primary-dark', dark);
root.style.setProperty('--primary-light', light);

之后全站 CSS 只引用变量。换主题色 = 改一行 JSON，所有按钮、标签、圆点指示器、悬浮卡片同时换装。

为什么比例是 0.28 和 0.92

深色太浅会分不清是否 hover，太深会发黑发闷；浅底太实会盖过正文，太透会失去「高亮」的提示感。0.28 与 0.92 是在这两头之间试出来的平衡点——这类参数本身也值得抽成配置项（本站放在 common.js 的 INTERNAL 对象里），而不是散在逻辑中间。

一个容易踩的坑：变量要「在定义处」读

JS 需要拿到当前列数来计算导航分页时，如果去 :root 上读 --nav-cols，读到的是空——因为这个变量定义在 .nav-cards 上，还会被媒体查询按屏宽覆盖。getComputedStyle 遵循 CSS 变量的作用域规则：必须到「最终生效的那个定义元素」上去取。

var cardEl = document.querySelector('.nav-cards');
var cols = getComputedStyle(cardEl).getPropertyValue('--nav-cols');

给中性色也建立「语义层」

新手组织变量时常按色值命名：--gray-1 到 --gray-9。写界面时却要不停回忆「边框是 gray-3 还是 gray-4」。更实用的做法是在色阶之上再包一层语义变量：

:root {
  /* 色阶（原材料） */
  --gray-900: #1f2328;
  --gray-500: #6b7280;
  --gray-200: #eaecef;

  /* 语义（界面实际引用） */
  --text: var(--gray-900);
  --text-2: var(--gray-500);
  --border: var(--gray-200);
}

界面样式只允许引用语义层。将来做暗色模式时，不用逐个改组件，只要在 [data-theme="dark"] 下把语义变量重新映射到不同色阶——文字变浅、边框变深，一套组件自动适配。本站后来加暗色模式，靠的就是这层预留。

实战迁移清单

  1. 先盘点：把全站颜色去重，你会发现 80% 的色值其实只对应不到十个语义；
  2. 定命名：按「用途」而不是「颜色」命名（--danger 而不是 --red）；
  3. 收敛入口：决策色写进 JSON 配置，衍生色在启动时注入，CSS 只引用变量；
  4. 留扩展点：中性色分色阶层和语义层，为主题切换留好位置；
  5. 最后替换：逐个文件消灭硬编码色值，替换完用搜索确认「没有漏网之鱼」。

配色系统和代码一样：一个入口（决策），多条通路（推导）。入口唯一，改起来才不慌。
